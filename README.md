## 🚀 Инструкция по установке

```bash
# Склонируйте репозиторий и перейдите в папку проекта
git clone https://github.com/kondrashov-m/BackEnd-student
cd BackEnd-student
git checkout lab18

# Запустите приложение
dotnet run
```
